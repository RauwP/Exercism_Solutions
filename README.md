# Exercism Python Solutions

A collection of solutions for exercises from the [Exercism](https://exercism.org/) Python track. This repository serves as a personal log of problem-solving, algorithm implementation, and idiomatic Python practice.

## 📁 Repository Structure

Each exercise is contained in its own directory with the solution implementation and test suite:

- **`all-your-base`** — Convert numbers between arbitrary bases.
- **`armstrong-numbers`** — Check if a number is an Armstrong number.
- **`change`** — Find the optimal change for a given amount using a set of coins.
- **`collatz-conjecture`** — Calculate steps to reach 1 using the Collatz sequence.
- **`connect`** — Compute the winner of a Hex game board.
- **`grains`** — Calculate the number of grains of wheat on a chessboard.
- **`guidos-gorgeous-lasagna`** — Introduction to Python basics with lasagna cooking times.
- **`hello-world`** — The classic introductory exercise.
- **`killer-sudoku-helper`** — Combinations generator for Killer Sudoku cages.
- **`leap`** — Determine if a given year is a leap year.
- **`matching-brackets`** — Validate matching brackets, braces, and parentheses.
- **`rectangles`** — Count rectangles in an ASCII diagram.
- **`spiral-matrix`** — Generate a square matrix filled in spiral order.
- **`swift-scheduling`** — Scheduling logic implementation.
- **`tree-building`** — Build a tree data structure from flat records.
- **`triangle`** — Determine triangle types (equilateral, isosceles, scalene).
- **`variable-length-quantity`** — Implement variable-length quantity encoding/decoding.

## 🛠️ Running Tests

The test suites for these exercises are written using `pytest`. To run tests for any specific exercise, navigate to its directory and run:

```bash
pytest
```

Make sure you have pytest installed in your active Python environment:
```bash
pip install pytest
```
